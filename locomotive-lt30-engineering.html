CURRENT LOCOMOTIVE REVIEW · LT 30

A cartridge with room for the crushed core

The revised restraint keeps a physical residual core, uses a separate hard ring, and includes a local removal route. The main bearing and housing still carry the shown catch load; an engineer must accept that path or replace it with an independent frame restraint.

Decision required before detailing proceeds

OptionWhat is availableUnresolved acceptance
A · Pivot-mounted cartridgeCoordinated physical candidate and local installation/removal geometry.Truck cage/caps → bearing races → inner-ring face → pusher/core → backing seat → cheeks/crosshead → frame. Bearing axial impact, caps/retainers and combined loads are unapproved.
B · Independent frame restraintA defined alternative load-path requirement; no accepted anchors or 3D mechanism.Separate truck/body anchors and articulated safety link must bypass the main pivot bearing. Engineer must define failure independence, articulation, loads, package and attachments.

The hard ring bypasses the crush core at bottoming; it does not bypass the main bearing. Neither option is selected for fabrication. The running-gear engineer must define the credible link-failure event and choose the load path. No professional assessment has been received in this revision.

Focused running-gear review request

  1. Select the main-bearing path or require a separate frame restraint. State the accepted bearing/cage/cap/race-retainer loads and failure modes.
  2. Define the credible failure event: relative speed, continued traction/braking, effective masses, orientation changes, load factors and post-failure wheel guidance.
  3. Review 75–85 kN core target and 20 mm working stroke; define onset/overload limits and reject or revise the package if required.
  4. Check complete local/global load paths, including pusher bending, new cheek bores, pin notches, welds, rails, fatigue and jam/bottoming cases.
  5. Confirm tolerances, core/keeper adjustment, positive retention and an accessible truck-separation/replacement method.
